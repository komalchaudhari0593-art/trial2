📋 Structure Tree JSON Format & Sample Template
You can import any system structure tree directly into the workstation using a JSON file. Ensure your JSON file follows the format below with items containing name, partNumber, parentId, description, and isAssembly properties. 
[
  {
    "id": "tree-root-01",
    "name": "Fifth Wheel Coupling System",
    "partNumber": "FW-SYS-900",
    "parentId": null,
    "description": "Complete fifth wheel heavy commercial vehicle coupling system with primary locking jaw, wedge, safety latch, and sensing package.",
    "isAssembly": true,
    "status": "Not Started"
  },
  {
    "id": "tree-sub-01",
    "name": "Locking Mechanism Sub-Assembly",
    "partNumber": "FW-LOCK-300",
    "parentId": "tree-root-01",
    "description": "Sub-assembly housing jaw lock, secondary safety latch, operating lever, and compression spring mechanism.",
    "isAssembly": true,
    "status": "Not Started"
  },
  {
    "id": "tree-comp-01",
    "name": "Locking Jaw Bolt Component",
    "partNumber": "FW-BOLT-102",
    "parentId": "tree-sub-01",
    "description": "High-tensile alloy steel bolt securing locking jaw to main casting plate under 150 kN load rating.",
    "isAssembly": false,
    "status": "Not Started"
  },
  {
    "id": "tree-comp-02",
    "name": "Electronic Proximity Sensor",
    "partNumber": "FW-SENS-405",
    "parentId": "tree-root-01",
    "description": "Inductive proximity sensor detecting kingpin engagement status for cabin dashboard indication.",
    "isAssembly": false,
    "status": "Not Started"
  }
]
📌 Key Field Descriptions:
• name: Component or assembly title (Required)
• partNumber: Part reference number or drawing code
• parentId: Set to parent node's id for sub-assemblies/components, or null for top-level root folders
• description: Detailed functional scope and engineering notes passed directly into AI prompt generation
• isAssembly: true for parent folder assemblies, false for leaf component files
